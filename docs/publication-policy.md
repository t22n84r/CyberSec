# Evidence, scope and publication policy

[Back to portfolio](../README.md)

This repository documents authorized training and independent homelab work. It does not report testing against employers, clients or unrelated systems.

## Evidence labels

- **Screenshot-supported:** a specific visible observation exists in the reviewed source images.
- **Completed according to notes:** the lab record states completion; a fresh platform run or independently verified certification is not implied.
- **Unconfirmed:** the attempt did not produce the required evidence or solved status.
- **Documented project:** a narrative exists; absent code or logs are identified.
- **Proposed retest:** a recommended validation step, not a test already performed.

## Sanitization

Public files omit passwords, session cookies, reset tokens, API keys, TLS session secrets, private keys, personal filesystem details, exact home addresses, private service domains, MAC addresses and real internal IP assignments. Generic lab usernames supplied by the training platform may appear in illustrative requests. No real lab instance hostnames are retained.

Screenshots and Word files were reviewed for evidence but are not committed. Sanitized excerpts are text transcriptions or representative request patterns, clearly labeled. The repository contains no packet captures, runtime configurations, Terraform state, encrypted secret stores, exploit binaries or TLS key logs.

## Authorship and technical accuracy

The work is Taanvir Nazmee’s training and independent project record. AI assisted with portfolio editing and organization; the Python proxy notes also explicitly describe AI-assisted development. Newly generated prose is not new test evidence. Original lab scripts were not supplied, so none have been reconstructed and passed off as historical implementations.

Findings are described without invented CVSS scores, business-impact metrics, uptime guarantees, certificates or professional job titles. Recommendations are kept separate from implemented controls. The public summaries correct unsupported database identification, exact parser-internals claims and universal traffic-capture claims from the drafts.
